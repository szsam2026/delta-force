iOS Safari
点击底部「分享」按钮 → 选择「添加到主屏幕」 → 命名后确认。
Android Chrome / Edge

云端同步设置

配置方法（只需做一次）
  1. 打开 jsonbin.io 注册免费账号
  2. 进入 API Keys 页面，复制 Master Key
  3. 进入 Bins 页面 → Create Bin，内容随便填 {}，创建后从地址栏复制 Bin ID
  4. 用文本编辑器打开本 HTML 文件，找到顶部注释里的 JSONBIN_CONFIG
  5. 把 Key 和 Bin ID 填入 API_KEY 与 BIN_ID 引号内
  6. 保存文件 → 刷新页面，即可自动启用云同步
同步策略：自动比对本地 / 云端时间戳，较新的一方胜出，避免旧数据覆盖新数据。
